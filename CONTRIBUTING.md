# Contributing

This project is written to be submittable to Proxmox upstream
(pve-devel) or handed over intact:

- Backend: Perl, following the Proxmox Perl Style Guide.
- UI: JavaScript/ExtJS, eslint clean, Proxmox JavaScript Style Guide.
- Rust only where a component justifies it (none in v1).
- Small, self-contained, reviewable commits; imperative subjects.
- License: AGPL-3.0. Upstream submission requires a signed Proxmox
  contributor license agreement (Harmony CLA, individual or entity)
  sent to office@proxmox.com — arrange it before submitting, not
  before contributing here.
- No coordination post to pve-devel is planned (by decision,
  2026-10-14); conventions come from Proxmox's published
  Developer Documentation.
